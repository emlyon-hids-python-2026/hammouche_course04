# hammouche_course04

A Python project for the emlyon business school Python programming course.

## Installation

```bash
git clone https://github.com/emlyon-hids-python-2026/hammouche_course04.git
cd hammouche_course04
uv sync
```

## Usage

```bash
uv run scripts/demo.py
```

## Project structure

- `data/`: datasets (not tracked by git)
- `notebooks/`: Jupyter notebooks
- `scripts/`: Python scripts
- `src/`: Python package
